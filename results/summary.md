# Results summary

Generated by `uv run python -m eval.run_all` from the committed labels and caches, with
no API calls. Every number in the README comes from this file. Details for each
evaluation are in its own `results/e*_summary.md`.

## Dataset

- **26 public clips** of instep kicks (`data/manifest.csv`): 23 for
  evaluation (18 tuning, 5 held out and never used to set a
  threshold) and 3 filmed from the wrong angle, kept to test the
  quality gate.
- **Hand labels (Aamir):** keypoints on 43 frames of 19 clips
  (516 body points); the contact frame on 19 evaluation clips;
  camera angle OK or not on 25 clips.
