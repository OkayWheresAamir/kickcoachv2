## Caveats

- **n = 15 questions, one run each.** The model isn't deterministic; a rerun from an empty cache would give different answers.
- **Claude wrote the questions, the expectations and the agent.** The expectations were fixed before any run (sha256 above), but nobody independent wrote them.
- **The wording checks are phrase lists**, not judgements of meaning. A correct answer in other words fails them; a wrong one with the right words passes.
- **Grounding is checked by value, not by meaning:** a number a tool returned, used for the wrong thing, still counts as grounded.
- **Fixture players,** not real users or real progressions.
